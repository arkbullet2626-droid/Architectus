**Architectus 0.1.1: use it for free with Google Gemini**

**Download:** `Architectus-Setup-0.1.1.exe` below. It installs over 0.1.0 and keeps your keys and library.

### What's new
- **Google Gemini is now the free option.** Get a key from Google AI Studio with just a Google account, no card needed. Gemini is listed first and is the default for new installs.
- A "FREE" badge and a short explanation of the free tier's limits on the Gemini card in Settings.
- A "Get a free Gemini key" link on the Generate page when no key is saved yet.
- Clearer messages when you hit Gemini's free-tier limit or run out of API credit.
- OpenAI and Anthropic cards now explain that their keys need prepaid API credit.
- Build pipeline updated (removes the Node.js 20 warning).

Windows SmartScreen may warn on first run because the installer isn't code-signed yet: choose **More info → Run anyway**.
