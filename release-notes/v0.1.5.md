**Architectus 0.1.5: new look**

**Download:** `Architectus-Setup-0.1.5.exe` below. It installs over earlier versions and keeps your keys and library.

### What's new
- Architectus now matches the Opifex Studios website: warm black background, cream text, amber buttons and links, a subtle amber-to-orange glow line, and green "FREE" labels.
- New amber logo, icon and setup wizard artwork.
- The app is now always in this dark theme, so the Light/Dark/System option has been removed from Settings.

Windows SmartScreen may warn on first run because the installer isn't code-signed yet: choose **More info → Run anyway**.
