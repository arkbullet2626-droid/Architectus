**Architectus 0.1.3**

**Download:** `Architectus-Setup-0.1.3.exe` below. It installs over earlier versions and keeps your keys and library.

### Fixes
- **Copied prompts keep their line breaks.** Copy now uses standard Windows line endings, so headings and lists no longer get squashed together when pasted into ChatGPT, Claude, Gemini, Notepad or a file.

### Smarter Architect (official builds)
- The AI is told to **ask for missing details first** right after the details list and again at the end, so it no longer skips straight to writing.
- Non-English requests get **fully translated headings** (no more English section names in a French prompt).
- Fewer, smarter placeholders: technical choices like file-naming patterns or operating system get sensible defaults instead of questions.
- Image prompts use clear descriptions instead of keyword spam like "8k" or "Unreal Engine".
- Health, fitness, money and legal requests now include safety-minded guidance.

Windows SmartScreen may warn on first run because the installer isn't code-signed yet: choose **More info → Run anyway**.
