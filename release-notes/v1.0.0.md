**Architectus 1.0: type something rough, get a master prompt.**

A free, open-source Windows app by [Opifex Studios](https://opifexstudios.ca) that turns casual requests into structured, ready-to-paste prompts for ChatGPT, Claude, Gemini or any other AI.

**Download:** `Architectus-Setup.exe` below. Windows 10 (1809+) / Windows 11, 64-bit. Installs over any 0.1.x version and keeps your keys and library.

### Highlights
- **Free with Google Gemini**: get a free key from Google AI Studio, no card needed. OpenAI and Anthropic keys work too.
- **The Architect**: Opifex Studios' tuned meta-prompt adds expert know-how for each kind of task, a "Details to fill in" list, an ask-first instruction and a built-in quality check.
- **Streaming output**, edit in place, one-click copy with clean formatting.
- **Local library** with search, edit and delete.
- **Any language**: prompts come back in the language you wrote in.
- **Private by design**: keys in Windows Credential Manager, no accounts, no analytics, no update checks. Requests go only to the AI provider you choose.
- The Opifex Studios look: warm black, cream and amber.

### New since 0.1.5
- Privacy policy, Source code and Report a problem links in Settings → About.
- The installer now has a fixed name (`Architectus-Setup.exe`) so the website download link always gets the newest version.
- `SHA256SUMS.txt` and logo files are attached to every release.

Windows SmartScreen may warn on first run because the installer isn't code-signed yet: choose **More info → Run anyway**.
