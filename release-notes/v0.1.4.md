**Architectus 0.1.4**

**Download:** `Architectus-Setup-0.1.4.exe` below. It installs over earlier versions and keeps your keys and library.

### Fixes
- **Prompts come back in the right language.** Short English requests like "workout plan" were sometimes answered in French. Language is now taken only from your request, with English as the fallback.
- No more outdated example dates in placeholder hints.

### Better quality on the free tier
- The default Gemini model is now **gemini-flash-latest** (still free), which follows the Architect's instructions more reliably than the Lite model. Lite is still available in Settings if you want maximum speed.

Windows SmartScreen may warn on first run because the installer isn't code-signed yet: choose **More info → Run anyway**.
