First public build of **Architectus**, a free, open-source Windows app that turns rough requests into polished master prompts.

**Download:** `Architectus-Setup-0.1.0.exe` below. Windows 10 (1809+) / Windows 11, 64-bit.

### What's in 0.1.0
- Generate master prompts with OpenAI, Anthropic (Claude) or Google Gemini using your own API key
- Streaming output, editable result, one-click copy
- Prompt library saved locally, with search, edit and delete
- Model picker with fast, cheap defaults and "Load models from my account"
- API keys stored in Windows Credential Manager, never in a file
- Setup wizard with optional desktop shortcut; uninstaller can remove saved keys and data

Windows SmartScreen may warn on first run because the installer isn't code-signed yet: choose **More info → Run anyway**.
