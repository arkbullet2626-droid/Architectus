**Architectus 0.1.2: a much smarter Architect**

**Download:** `Architectus-Setup-0.1.2.exe` below. It installs over earlier versions and keeps your keys and library.

### What's new
- Upgraded Architect meta-prompt in official builds:
  - A **Details to fill in** list with every placeholder explained and an example, so results come out personal instead of generic.
  - The AI now **asks for missing details first** before writing.
  - Built-in expert best practices for each kind of task (job applications, code, research, planning, marketing, learning and more).
  - A **Quality check** section so the AI reviews its own work before answering.
  - Image and video requests get a proper visual prompt instead of a text-style one.

Windows SmartScreen may warn on first run because the installer isn't code-signed yet: choose **More info → Run anyway**.
